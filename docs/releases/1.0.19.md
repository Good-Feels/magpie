# Magpie 1.0.19

Open **Magpie → Settings → MCP** to connect an assistant. **Connect to Claude** opens the Magpie extension installer in Claude Desktop. **Connect to ChatGPT** gives you a setup prompt to use in Codex for a private connection to ChatGPT.

To try the connection, enable sharing and right-click a sample text clip in Magpie. Choose **Share with AI**, then ask your assistant to find and read the clip. Use **Stop Sharing All** to revoke access to the shared clips.
