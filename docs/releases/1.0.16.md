# Magpie 1.0.16 (build 17) candidate

Prepared November 17, 2026. Fixes from the security/bug audit:

- Preserve history when its database cannot open; show that saving is paused instead of resetting all history.
- Ignore confidential/transient clipboard content and conservatively honor excluded-app focus transitions. Discard a capture if the clipboard changes while its payload is decoded.
- Apply the 200-clip fresh-install default consistently. Preserve existing no-preference history as Unlimited, and keep explicit user choices and pins.
- Save and restore complete ordered file selections, preserving existing single-file history and comparing full payloads for deduplication.

The grouped-file migration adds one nullable column. It does not delete old rows. Dependencies remain GRDB 7.10.0, Sparkle 2.9.0, KeyboardShortcuts 2.4.0 and Mixpanel 4.4.0; lockfiles are now versioned. No analytics schema, endpoint or consent setting changed.

Validation: the project-owned regression catalog is in `docs/TESTING.md`; saved run evidence is under `Tests/evidence/2026-11-17/`. App/keeper coverage is preserved and 20 meaningful engine regressions replace the placeholder test. Read the final receipt for exact revision/content hashes, commands, environment and coverage limitations.

This file is a release-preparation record. GitHub publication, tags and signed appcast changes wait for the final release authorization. Installed Sparkle upgrading is a separate post-publication gate, and the installed app is never replaced manually.
