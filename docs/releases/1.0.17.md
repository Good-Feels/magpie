# Magpie 1.0.17

Magpie can now share individual text clips with AI assistants over the Model Context Protocol (MCP). Open **Magpie → Settings → MCP** for setup, then right-click a text clip and choose **Share with AI**. Sharing starts off and clients can only search and read clips you select. Turning sharing off or quitting Magpie clears the selection.

Claude Desktop connects locally. ChatGPT connects through OpenAI Secure MCP Tunnel. The setup guide also covers Claude Code and Codex.

[Magpie MCP setup guide](https://github.com/Good-Feels/magpie/blob/main/docs/MCP.md)
